# SPN Esport — site prêt à publier

## Structure

- `index.html` : page d’accueil
- `compte.html` : connexion, inscription, cups et administration
- `assets/` : images du site
- `firebase/` : configuration et règles de la base de données
- `docs/` : guide d’activation Firebase

Ouvre `index.html` pour commencer. Pour activer les vrais comptes, suis `docs/INSTALLATION-FIREBASE.md` puis publie tout le dossier sur un hébergement Web.
